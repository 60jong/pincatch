# catch pin — 변경 사항 (2026-10-10 인수인계 이후)

이 문서는 지난 인수인계 묶음(`DESIGN_SPEC.md` + 화면 8개) 이후 바뀐 정책과 디자인이다.
충돌하면 **이 문서와 `DESIGN.md`가 `DESIGN_SPEC.md`보다 우선**한다.
화면 파일명은 `design/screens/` 기준이며, 다크 버전은 같은 이름 뒤에 `Dark`가 붙는다.

---

## 1. 폐기된 것 (코드에서 제거)

| 폐기 | 대체 |
|---|---|
| "잡는 중" 오버레이 (진행 링, 결과 무관 동일 연출) | 평소엔 즉시 결과 토스트, 거의 동시일 때만 판정 대결 연출 (2-1) |

| 탭바 높이 80 | 88 |

## 2. 정책 변경

### 2-1. 핀 결과 알림과 판정 연출
- 평소에는 핀을 누르면 **결과 토스트**만 띄운다.
  - 위치: 탑바 아래에 쌓임(최대 3개)
  - 표시 시간: 성공 5초, 실패·탭권 없음 2.2초, 탭하면 바로 닫힘
  - 성공하면 포인트가 0.7초 동안 카운트업하고, "+NP" 칩이 뜨고, 탭권이 1장 줄어든다.
- **판정 대결 연출**은 상대와 거의 동시에 눌렀을 때만 띄운다(차이 기준값은 서버 설정).
  - 화면: `JudgeWin`, `JudgeLose`
  - 타임라인: `DESIGN.md` "판정 대결 연출"
- 결과 화면에 **"다음부턴 간단한 알림만 받기"** 체크가 있고, 내 정보 > 판정 연출 스위치와 같은 설정이다. 끄면 거의 동시여도 토스트만 띄운다.
- 판정은 여전히 서버에서만 한다. 연출은 서버 결과가 도착한 뒤 재생한다.

### 2-2. 광고 보고 2배 받기
- 성공 토스트와 판정 이김 화면에 **"2배 받기"** 버튼을 둔다.
- 받지 않은 건은 **2배 대기 보상**으로 서버에 30분 보관한다(만료 시 소멸).
  - 화면: `HomeDouble`
  - 홈 하단 패널에 "2배로 받을 수 있는 포인트 +NP · 남은 시간" 줄
- 광고 1편으로 1건을 2배로 한다. 2배 광고와 탭권 충전 광고는 **같은 하루 광고 한도**를 쓴다.
- 지급은 AdMob 서버 검증(SSV) 콜백에서만 한다.

### 2-3. 휴대폰 인증 (octomo, MO 방식)
- **방식**: 사용자가 받는 번호로 인증 문구를 문자로 직접 보낸다. 실명 확인은 하지 않는다.
- **흐름**: 번호 입력 → "문자 한 통이면 휴대폰 인증 끝!" → 문자 앱에서 보내기 → 앱으로 돌아오면 폴링 + "문자 보냈어요 · 인증 확인" 버튼 → 완료 화면(사용자가 직접 확인 버튼을 누름).
- **가입 6단계**에서는 건너뛸 수 있다(`SignupPhone`, `SignupPhoneSms`, `SignupPhoneDone`).
- **상품권 교환에는 필수**다. 교환 화면에 인증 안내 게이트를 둔다(`ExchangeDetail`).
- **설정 > 인증 관리**에서 상태를 확인하고 인증한다(`VerifyCenter`, `VerifyCenterDone`, `PhoneVerify*`). 내 정보와 계정 관리에 미인증 배지를 띄운다.
- 실패, 시간 초과(5분), 도움말 시트, 건너뛰기 확인 시트를 포함한다.

### 2-4. 온보딩 순서
로그인 → 약관 동의(필수 4 + 선택 마케팅) → 위치 권한 → 알림 권한 → 닉네임(2~12자) → 휴대폰 인증(건너뛰기 가능) → 홈

### 2-5. 화면 모드
- 내 정보 > 화면 모드에서 **시스템 / 라이트 / 다크**를 고른다(`DisplayMode`). 기본값은 시스템이고, 기기에 저장한다.
- **모든 화면**은 라이트와 다크를 지원한다.

## 3. 디자인 변경

- **기준 문서**: `DESIGN.md`(디자인 원칙). 금지 목록, 색 토큰(라이트/다크), 컴포넌트, 모션, 지도, 구현 함정이 들어 있다.
- **홈 지도**: 실제 지도 SDK를 쓰지 않는다. Skia로 직접 그리는 플랫 일러스트 지도다.
  - 생김새: 둥근 블록 타일 + 아래 4px 테두리, 큰길에만 흰 점선
  - 지형 6종: 도심, 아파트 단지, 강변, 산, 바다, 논밭(`Map*`)
  - 구현 방법: `DESIGN.md` "지도 표현 > 개발 팁"
- **홈 하단 패널**: 손잡이로 접고 펴고, 2배 대기 줄, 실시간 피드 한 줄.
- **판정 대결 연출**: 남색 배경에 폰 두 대, 터치 원, 민트 번개 하나, 결과 화면이 퍼지는 전환(이김 초록 / 짐 회색).
  - 화면에 연출 문구는 없다.
  - 손가락 그림, 흔들림, 강한 번쩍임은 금지다.
- **애플 스타일 잔재 제거**: iOS 시스템 색, 글래스 카드, 흐린 그림자 탭을 모두 우리 토큰과 플랫 스타일로 바꿨다.
- **글자 굵기**: 화면·목록 제목은 900, 포인트 숫자는 Sora 800.
- **스크롤 화면**: 목록 카드에 `flex-shrink: 0`을 줘서 찌그러지지 않게 한다.

## 4. 서버·데이터 영향 (새로 필요)

- `pending_double_rewards`: 사용자, 핀, 포인트, 만료 시각(+30분), 상태
- 일일 광고 사용 횟수: 탭권 충전과 2배 받기 공용 카운터
- 판정 결과에 **두 사용자의 시각 차이(ms)**를 포함해 연출 여부와 결과 문구에 사용
- 휴대폰 인증 상태: octomo 요청 ID, 인증 문구, 만료, 인증 완료 시각. 교환 API에서 인증 여부 검사
- 사용자 설정: 판정 연출 on/off, 화면 모드(기기 저장), 알림 항목별 on/off, 야간 알림 끄기
- 초대 코드와 보상 지급 조건(피초대자 첫 핀 획득)
- 지도 데이터: 내 주변 600m의 단순화된 OSM 벡터 JSON 제공 API
